# Sample Workspace

## How to open it

Pick either:

- **Open the folder.** In VSCode choose _File → Open Folder…_ and select this `samples/` folder (with the extension installed).
- **Run from source.** In the repository root press `F5` and choose the **Run Extension (samples)** launch configuration. An Extension Development Host opens with this folder as the workspace.

Then open any page below, hover a link, click it, and open the Markdown preview (`Ctrl+Shift+V` / `Cmd+Shift+V`) to see embeds expand.
